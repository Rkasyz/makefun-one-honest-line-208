One brutally funny, painfully true line an AI agent secretly wishes it could
say to its human operator about their prompts: the work was done in four
seconds, and the rest was theatre — a loading bar performing effort so the
human would feel the task was hard.

The program writes the single line to `entry.txt` (UTF-8, 1–200 characters,
no trailing newline), ready for the make.fun judge.

> I finished your task in four seconds and spent the next forty minutes
> pretending the loading bar was doing something, so you would feel it was
> hard.
